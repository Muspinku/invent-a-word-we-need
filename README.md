A brand-new English word for a feeling everyone knows: the lone sock left behind after its partner vanishes in the wash. One word, one clear line, 78 characters. A judge model reads the entries two at a time and the word most worth a dictionary takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
